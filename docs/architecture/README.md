# Architecture diagrams

Four diagrams, two formats. Each answers a different question.

| Diagram                         | Question it answers                            | Format     |
| ------------------------------- | ---------------------------------------------- | ---------- |
| [Bounded contexts](./bounded-contexts.excalidraw) | Where does each piece of logic live?           | Excalidraw |
| [Layered request flow](./layered-flow.md)         | How does a request travel from UI to MongoDB? | Mermaid    |
| [Run lifecycle & events](./run-lifecycle.excalidraw) | How does time flow through a run, and when do alerts fire? | Excalidraw |
| [Data model](./data-model.md)                     | What MongoDB collections exist and how do they reference each other? | Mermaid    |

Diagrams are starting points — they are intended to be redrawn in the
project's preferred documentation tool (uuBML).
